Toutes les routes API sont définies dans `routes/api.php` et préfixées automatiquement par `/api`. La documentation OpenAPI générée par `l5-swagger` est disponible sur `/api/documentation`.

## Conventions

- **Format** : JSON en entrée et en sortie sur toutes les routes `/api/*`.
- **Authentification** : `Authorization: Bearer <token>` (Sanctum) sur les routes protégées — voir [Authentification](/architecture/authentification).
- **Multi-établissement** : en-tête `X-Etablissement-Id` sur les routes protégées pour indiquer l'établissement courant.
- **Erreurs d'authentification** : réponse JSON 401 (pas de redirection HTML).

## Endpoints publics (sans authentification)

| Méthode | Route | Rôle |
|---|---|---|
| `POST` | `/auth/login`, `/auth/verify-otp`, `/auth/resend-otp` | Connexion par email + OTP |
| `POST` | `/auth/login-phone`, `/auth/verify-otp-phone`, `/auth/resend-otp-phone` | Connexion par téléphone + OTP SMS |
| `POST` | `/auth/register` | Inscription |
| `POST` | `/paiements/webhook/jeko` | Webhook de confirmation de paiement Jeko (authentifié par signature) |
| `GET` | `/public/eleves/fiche/{token}` | Fiche élève publique via QR code |
| `GET` | `/public/eleves/verification-qr/{token}` | Vérification de paiement via QR |
| `GET` | `/public/frais-scolaires` | Liste des frais scolaires (ex. poste d'accueil, sans connexion) |
| `GET` | `/paiements/{paiement:recu_numero}/recu` | Reçu de paiement public via QR |
| `GET` | `/paiements/groupes/{groupe}/recu` | Reçu d'un groupe de paiements |
| `POST` | `/pointage/hikvision/{numero_serie}/{cle}` | Webhook terminal biométrique Hikvision |
| `GET` | `/status` | Statut JSON des composants de la plateforme |

<Note>
  Les endpoints publics `fiche` et `verification-qr` sont soumis à un throttle de 30 requêtes/min.
</Note>
