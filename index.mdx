SmartEcole Backend est l'API qui alimente la plateforme SmartEcole, une solution de gestion scolaire complète : élèves et inscriptions, pédagogie (notes, bulletins), finances et paiements mobile money, présences par badge biométrique, communication avec les parents, boutique scolaire, cantine et transport.

L'API est construite avec **Laravel 12** (PHP 8.2+), expose des endpoints JSON authentifiés par **Laravel Sanctum**, et gère nativement le **multi-établissement** (une même instance peut servir plusieurs écoles).

## Stack technique

| Composant | Technologie |
|---|---|
| Framework | Laravel 12, PHP ^8.2 |
| Authentification | Laravel Sanctum (tokens API) |
| Base de données | MySQL (SQLite en local par défaut) |
| Cache / Queue / Session | Driver `database` (Redis en option) |
| Stockage fichiers | Disque public en local, AWS S3 en production (Laravel Cloud) |
| PDF | `barryvdh/laravel-dompdf` (bulletins, reçus) |
| QR codes | `endroid/qr-code` (fiche élève, vérification de paiement) |
| SMS / OTP | Passerelle Sinexus via WebSocket |
| Paiement mobile money | Jeko (Wave, Orange Money, MTN Money, Moov Money) |
| Documentation API générée | `darkaonline/l5-swagger` (OpenAPI, `/api/documentation`) |
| Observabilité | Laravel Nightwatch |

## Modules fonctionnels

<AccordionGroup>
  <Accordion title="Administratif">
    Établissements, licences, utilisateurs et rôles, élèves et leurs documents, inscriptions, classes, matières, emplois du temps, niveaux, bâtiments, salles, années et sessions scolaires.
  </Accordion>
  <Accordion title="Pédagogie">
    Évaluations, notes, calcul de moyennes, bulletins (trimestriels et annuels, PDF), devoirs à la maison.
  </Accordion>
  <Accordion title="Finances">
    Frais scolaires, échéanciers (avec ajustements par élève), paiements (espèces et mobile money via Jeko), dépenses, remises, bourses, situation financière par élève.
  </Accordion>
  <Accordion title="Présences">
    Pointage biométrique (Hikvision, relais ZKTeco), transformation des badges en présences, justification et validation des absences/retards, clôture automatique quotidienne.
  </Accordion>
  <Accordion title="Communication">
    Communications ciblées, annonces (avec diffusion programmée), événements et médias.
  </Accordion>
  <Accordion title="Services annexes">
    Boutique scolaire (articles, panier, commandes), menus de cantine, trajets de transport avec abonnés.
  </Accordion>
</AccordionGroup>
